# League Cloud Coach

Your games. A clearer perspective.

A personal League of Legends video library with Google sign-in and account-free watch links. Upload to YouTube as **Unlisted**, add the link, and share a watch page with your coach.

```sh
cd web
npm ci
npm run dev
```

See [setup and deployment](web/README.md) for Supabase, Google OAuth, and GitHub Pages. The development-only local preview works before cloud configuration. Real accounts and shared app watch pages require Supabase.

Video files and the native League Helper application are not included in this repository.
